# 資料欄位說明(趨勢雷達複製出來的提示詞 JSON)

在趨勢雷達點開個股、按「✨ 複製 Gemini 分析提示詞」,會得到一段文字,中間是一個 JSON。主要欄位:

| 欄位 | 意義 |
|---|---|
| 最新收盤價、最新成交日 | 官方收盤價與日期 |
| 日/五日/二十日漲跌百分比 | 以收盤價計算 |
| MA5、MA10、MA20 | 5/10/20 日均價 |
| 量比_對20日均量 | 當日量 ÷ 前 10 日均量(欄名沿用舊名) |
| 當日收盤位置_0到1 | (收盤 − 最低) ÷ (最高 − 最低) |
| 區間高點/低點 | 最近 90 個交易日內的最高、最低價與日期 |
| 系統趨勢分類 | 上升/下降/突破關注/跌破關注/盤整 |
| 三大法人買賣超_近期 | 外資、投信、自營商 最新一日、近5日、近20日合計(張) |
| 近12個月營收 | [月份, 單月營收(億元), 年增率%, 當年累計營收(億元)] |
| 股利估價雷達.股利估值 | 今年EPS(含推估)、去年EPS、年增率、各季EPS與來源、配息率、推估股利、便宜價、合理價、以最新收盤計的殖利率與分區、一次性獲利提醒 |
| 股利估價雷達.本益比 | 近四季本益比、以今年推估EPS計之本益比 |
| 股利估價雷達.近12季單季EPS | [季度, EPS, 已公告/推估] |
| 股利估價雷達.財報品質 | ROE、毛利率、營益率、負債比、同產業中位數、品質分數與九項檢核 |
| 估價表快照 | 我的 Excel 估價表:三大估價法價格、法人預估EPS、PEG、近四季ROE、營運現金流、獲利含金率、Beta、波動率、月營收備註 |

數值為 null 代表沒有這項資料(例如 ETF 沒有股利估值、金融股沒有毛利率)。金額單位新台幣,市值單位元,三大法人單位張。
